# Changelog

## 0.3.0-beta.1

- Added bounded automatic decomposition to the existing MCP scheduler, with planning-qualified routing and verified independent review for applicable patches.
- Added project-specific limits for concurrency, deadlines, batch size, quality, and independent review.
- Made graph expansion and batch cancellation transactional. Restart preserves pending cancellation and fences unconfirmed workers.
- Verified a live AGY coding DAG on synthetic Go code and added credential-free Intel macOS CI.
- Kept provider-native subagents experimental. AGY lacks an independently verifiable native child result, and the latest OpenCode Free child attempt was rate-limited.

## 0.3.0-alpha.4

- Reconciled older OpenCode Free cooldowns with newer verified same-route success and added bounded opt-in revalidation.
- Added explicit cooldown scope, normalized retry hints, and durable observation ordering.
- Qualified the signed AGY 1.5.4 base model for scoped read-only and opt-in trusted-local work.
- Verified four bounded synthetic roles and a cross-provider restart recovery with signed-integer boundary checks.
- Added experimental OpenCode native background correlation and deterministic Intel archive metadata.

## 0.3.0-alpha.3

- Added quality tiers and role-specific routing evidence, with configurable quality-first, balanced and conserve modes.
- Added separate AGY weekly reserves, bounded pacing estimates and native preflight enforcement.
- Added normalized Codex, AGY and OpenCode Free capacity, scoped cooldowns, and actionable warnings to the existing MCP tools.
- Added a quota-only pin for signed AGY 1.5.4. Inference admission remains pinned to its separately verified build.

## 0.3.0-alpha.2

- Added a durable planned checkpoint for synthetic trusted-local tasks, with different-provider resume and verification of restored preimages.
- Added a pinned OpenCode Free foreground child profile with separate parent and child session checks.
- Distinguished AGY child invocation errors from permission denials and required the parent result to match the owned child result.
- Kept native child and full live recovery acceptance open.

## 0.3.0-alpha.1

- Added discovery and bounded synthetic inference audits for pinned AGY and OpenCode clients.
- Added optional freshness-gated routing evidence and AGY family reservations.
- Added bounded native AGY and OpenCode read-only continuation and verified checkpoint restore.
- Added an experimental AGY native-child attempt policy with fail-closed ownership and result checks.
- Preserved the eight MCP tools, SQLite tables, M1 handoff and M2A trusted-local policies.

## 0.2.0 baseline

- Preserved the restricted default and Apache-2.0 source and package attribution.
